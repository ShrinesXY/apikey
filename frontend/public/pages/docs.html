AZPKEY Documentation

AZPKEY is a complete API key management system. Generate and manage API keys, monitor usage, and protect your endpoints with tier-based access control.

Base URL: https://azpkey.biz.id

Interactive API reference: Swagger UI →

Quick Start

Get started in 3 steps:

  1. Register an account at /pages/register.html
  2. Generate an API key from your dashboard
  3. Include the key in your request headers
curl https://azpkey.biz.id/api/data \
  -H "x-api-key: azp_your_key_here"

Authentication

The dashboard API uses JWT bearer tokens. Obtain a token by logging in, then include it in subsequent requests:

Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Protected API endpoints use an x-api-key header instead of JWT:

x-api-key: azp_64characterrandomhexstringhere...

Generate an API Key

You can generate keys from the dashboard or via the API:

POST /api/keys
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "My Production Key",
  "expiresInDays": 30,
  "ipWhitelist": "192.168.1.1, 10.0.0.1"
}

Response includes the full API key (only shown once at creation):

{
  "success": true,
  "data": {
    "key": "azp_a1b2c3d4e5f6...",
    "name": "My Production Key",
    "tier": "free",
    "requestLimit": 1000,
    "usageCount": 0,
    "status": "active",
    "expiresAt": "2025-06-15T12:00:00.000Z"
  }
}

Using a Key

Include your API key in the x-api-key request header for every protected request:

# cURL
curl https://azpkey.biz.id/api/data \
  -H "x-api-key: azp_yourkeyhere"

# JavaScript (fetch)
const response = await fetch('https://azpkey.biz.id/api/data', {
  headers: { 'x-api-key': 'azp_yourkeyhere' }
});

# Python (requests)
import requests
r = requests.get(
  'https://azpkey.biz.id/api/data',
  headers={'x-api-key': 'azp_yourkeyhere'}
)

# Node.js (axios)
const axios = require('axios');
const res = await axios.get('https://azpkey.biz.id/api/data', {
  headers: { 'x-api-key': 'azp_yourkeyhere' }
});

Tiers & Limits

AZPKEY has three tiers with different request limits and rate limits:

FREE 1,000 req/month 10 req/sec · 2 keys max
PRO 50,000 req/month 60 req/sec · 10 keys max · IP Whitelist
PREMIUM 500,000 req/month 300 req/sec · 50 keys max · IP Whitelist + Custom expiry

IP Whitelist

Pro and Premium keys support IP whitelisting. Only requests from listed IPs will be accepted. Leave empty to allow all IPs.

// Set when creating key
{
  "name": "Restricted Key",
  "ipWhitelist": "203.0.113.1, 198.51.100.0"
}

// Update existing key
PUT /api/keys/:id
{ "ipWhitelist": "203.0.113.1" }

Key Management Endpoints

All key endpoints require Authorization: Bearer <token>.

GET/api/keysList all your keys
POST/api/keysGenerate new key
PUT/api/keys/:id/regenerateRotate key (invalidates old key)
PUT/api/keys/:id/revokeRevoke key permanently
DEL/api/keys/:idDelete key
GET/api/keys/statsUsage statistics + chart data
GET/api/keys/logsRequest logs (paginated)

Protected API Endpoints

These endpoints require a valid x-api-key header.

GET/api/dataExample protected data endpoint
GET/api/data/pingQuick key validation ping

Error Codes

401 - Missing or invalid API key / JWT token
403 - Key revoked, expired, banned account, or IP not whitelisted
429 - Rate limit exceeded (per second) or request limit reached
400 - Validation error
404 - Endpoint not found
500 - Internal server error

All error responses follow this format:

{
  "success": false,
  "error": "API key has expired",
  "hint": "Generate a new key from your dashboard"
}

Rate Limits

Two layers of rate limiting are enforced:

  • Global: 500 requests per 15 minutes per IP (applies to all endpoints)
  • Per-key: Tier-based requests per second (Free: 10, Pro: 60, Premium: 300)
  • Monthly limit: Hard cap on total requests per key based on tier
  • Auth endpoints: 20 attempts per 15 minutes per IP

When a rate limit is exceeded, the response includes a retryAfter field:

{
  "success": false,
  "error": "Rate limit exceeded",
  "limit": "10 requests/second",
  "retryAfter": 1
}

Code Examples

Full workflow in JavaScript

// 1. Register
const register = await fetch('/api/auth/register', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ username: 'dev', email: 'dev@example.com', password: 'Password123' })
});
const { token } = await register.json();

// 2. Generate API key
const keyRes = await fetch('/api/keys', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${token}` },
  body: JSON.stringify({ name: 'My Key', expiresInDays: 30 })
});
const { data: { key } } = await keyRes.json();

// 3. Use the key
const data = await fetch('/api/data', {
  headers: { 'x-api-key': key }
});
console.log(await data.json());

Python

import requests

# Login
res = requests.post('https://azpkey.biz.id/api/auth/login', json={
    'email': 'you@example.com', 'password': 'yourpassword'
})
token = res.json()['token']

# Generate key
key_res = requests.post('https://azpkey.biz.id/api/keys',
    json={'name': 'Python Key', 'expiresInDays': 30},
    headers={'Authorization': f'Bearer {token}'}
)
api_key = key_res.json()['data']['key']

# Call protected endpoint
r = requests.get('https://azpkey.biz.id/api/data',
    headers={'x-api-key': api_key}
)
print(r.json())
